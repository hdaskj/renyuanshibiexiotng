# AI-03 相寻交互原型

## 打开方式

双击 `index.html`，或在本目录运行：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

原型是纯前端、离线可运行的单页交互演示，不依赖后端服务，不会上传或持久保存用户选择的文件。演示照片使用抽象人物示意，数据均为虚构。

## 演示路径

1. 勾选用途与权利确认，进入个人相册。
2. 点击任意照片的“解释”，查看人脸、衣着、场景三类证据。
3. 输入“穿蓝色针织衫，在木屋咖啡馆”，观察多模态重排。
4. 切换“人脸 / 衣着 / 场景”排序，打开或关闭“增加多样性”。
5. 对结果点击“相关 / 不相关”，查看反馈状态。
6. 点击“上传与索引”，选择照片并完成模拟特征提取。
7. 进入“授权与隐私”，演示撤回授权、停止检索和索引清理状态。

## 文件

- `index.html`：完整交互原型。
- `AI-03-分析设计与教师确认.md`：需求分析、交互设计、原型范围及待老师确认事项。
- `AI-03-教师评审确认单.pdf`：可直接提交老师的两页评审材料与确认清单。
- `AI-03-系统设计与接口.md`：架构、检索时序、授权状态、推荐策略、测试用例和实施顺序。
- `api/openapi.yaml`：可供后端开发使用的 OpenAPI 3.1 接口契约。
- `db/schema.sql`：PostgreSQL 业务元数据、授权、审计和删除任务表结构。

## 原型边界

本原型验证交互与产品逻辑，不包含真实 CLIP/InsightFace 推理、Milvus/Faiss 向量库、账户后端、灰度发布或生产级监控。正式实现时，照片检索接口、鉴权、审计、数据删除和监控链路必须与原型中的授权状态一致。
